# Middle-earth-TheOneRing 剧情地图中文本地化项目
该剧情地图由德国的PakPacman带领制作，并发布于PlanetMinecraft，见帖子：[Middle-earth: Complete Map With All Locations And Heroes With Story Quest's!](https://www.planetminecraft.com/project/middle-earth-complete-map-with-story-quest-s/)

在这个地图中，作者制作了4条主线还原电影六部曲的剧情，魔戒远征、收复孤山，甚至挑战史矛革、炎魔与巫王等。并且在世界各地包含众多支线，例如蓝袍巫师、格洛芬德尔、盗贼公会等，让你第一人称体验中土大陆的故事。

该地图添加了影视中出现的所有大型经典建筑，并不断进行翻建与修饰，部分地点是独家重做（例如墨瑞亚），质量要高于俄罗斯的通用建筑包。

欢迎来到中洲——一个充满冒险与史诗传说的地方。

历经多年持续开发，项目至今仍在不断成长壮大。

所有新增建筑都经过手动编辑并改进，确保它们能自然地融入环境。

来这个完全开放的世界，以前所未有的方式体验中洲吧。
数百条精心创作的对话，配上多种回答选项，正等你探索。
任务线将引领你追随英雄们的足迹，
沿途还能招募众多追随者。

但你是否能摧毁至尊戒，

目前该项目的汉化落后作者更新数个版本，该汉化项目最初是基于3.3版本汉化的，但如今地图已更新到了3.6版本，新版内容基本没有跟进汉化。

除此之外，原本3.3版本的翻译内容依然有三成为机翻，没有参考电影台词进行润色，若无意中发现问题，记得及时讨论修改。

## 文件结构：
你需要大体了解一下该项目涉及的文件与文件夹都是做什么用的，以及在什么位置。

该项目汉化的是剧情地图的自定义NPC模组的对话与任务，共分为三部分：

第一部分是对话框与选项，又称“对话框”，右键NPC会弹出的对话框，并有选项可以选择；

第二部分是任务手册，地图中做了很多任务，可通过对话框选项触发，获得任务后可在任务手册查看到任务相关信息；

第三部分是气泡型对话，又称“气泡台词”，会在头上弹出气泡，并显示在左下角聊天栏里。例如路人的问候和敌人的谩骂（目前没有找到很好的汉化应用方式，气泡型对话暂时可以不汉化）。

#### 对话框
对话框与任务手册的文本位于.minecraft\saves\存档名\customnpcs文件夹，其中：

> **dialogs**文件夹内是NPC对话框文本
>
> **quests**文件夹内是任务手册文本

在dialogs里的每一个文件都是一个NPC的对话框，里面是对话框的文本和选项。

## 工作内容说明：
你需要先前往Paratranz，注册账号后申请加入该项目的Paratranz。然后认真阅读下文的翻译须知。

## 汉化须知：
在动工之前，需要了解注意事项与要求标准。

在汉化之前最好先阅读一下已有的汉化，或者亲自玩一下剧情地图，基本就知道汉化质量与风格要求了。

1.**魔戒译名要求**：严格使用世纪文景版（邓嘉宛版）译名。比如“索隆”、“萨茹曼”，有人会习惯性的打成“索伦”、“萨鲁曼”，这样绝对不行，必须统一使用世纪文景版译名。由于我们已将魔戒Wiki的译名表导入进了Paratranz，因此在翻译词条时，Paratranz平台能自动检测到术语表中的专有名词并提示。但如果有专有名词没有自动提示，就一定要先搜索魔戒Wiki！

2.**模组专有名词**：如果遇到难以翻译的、不像常用词汇的词，那么很可能就是魔戒模组的专有名词，可以在魔戒传承版的Paratranz中查询。但该项目内仍有不少机翻内容，例如机翻出来的“航点”，应该改为“路径点”。

3.**句子每行长度限制**：对话与任务手册的每一行都不能过长，自定义NPC模组有bug，无法自动根据客户端界面大小为中文自动换行，所以我们需要限制每一行的字数，最好不超过35字。

4.**标点符号**：中文文本中请统一使用全角符号。请务必注意标点符号使用规范！例如英文句子都是?!"":等半角符号，翻译时必须改为？！“”：等全角符号。

5.**依据电影台词翻译**：这个地图里的对话绝大部分都来自于电影的台词。

如果感觉有些话有点难懂，不好翻译，说不定那是电影里的台词，可以尝试在谷歌里搜一下，如果能搜到，就说明是电影台词，直接使用B站片源的电影字幕的翻译就行了，只能使用B站片源的字幕，其他字幕不可使用。

B站片源的字幕翻译的非常标准，为标准的世纪文景译版，可以直接复制。B站片源的电影资源可以在汉化群中下载。

可以稍微参照着电影补充几句话，但是还是要考虑到这是个剧情地图，文本不适合太长。再比如，台词是对玩家说的，不是对弗罗多或者巴金斯，因此有些台词就不适合加了。

5.**润色**：该地图里的对话绝大部分都是电影里的台词，初翻并没有很精致，润色时可以使用DeepSeek，并且需要对照电影润色。

6.**诗歌翻译**：如果遇到诗、歌曲之类的，或者其他电影里没有的，可以参考原著，在中文译本里使用世纪文景的官方翻译。注意不要使用朱学恒的翻译。电子版原著可以在汉化群中查看。


### 手动修改汉化内容
如果你想不加入本汉化项目而是自己手动修改汉化内容，例如为自己的服务器做特制版本，那么你有以下几点需要注意：

1.不要汉化DialogTitle，这是对话框的标题，不是内容。一旦修改，会破坏对话系统，让对话无法连接。

> ![不要汉化DialogTitle](https://github.com/ArchiDreamZ/Middle-earth-TheOneRing-Chinese_localization/assets/89504984/2143b7e4-78eb-4d0e-81df-2e5161029bd6)

2.对话与任务手册的每一行都不能过长，自定义NPC模组无法自动根据客户端界面大小自动换行，所以我们需要限制每一行的字数，最好不超过35字左右。
